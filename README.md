# Hi, I'm spindriftpapilio

AI security research, practical testing tools, and knowledge sharing.

I'm a Chengdu-based developer focused on the security of large language models and AI Agents. My work explores prompt injection, multimodal inputs, and the security implications of giving AI systems access to tools, files, and external services. I build testing tools and organize research resources to make these topics easier to investigate and understand.

My main project is [IceSky](https://github.com/spindriftpapilio/icesky), a browser-based toolkit for multimodal prompt injection testing. It brings together text transformations, multi-turn conversation editing, and test sample generation across documents, images, audio, email, web content, MCP definitions, and Agent configurations. Local processing and sample generation run without a backend. Visit the [project website](https://icesky.securityforai1.com) to explore it.

I also maintain [AI-Agent-skills](https://github.com/spindriftpapilio/AI-Agent-skills), a collection of security assessment skills for coding Agents and AI-powered development tools. It covers areas such as workspace trust, approval mechanisms, MCP configuration, hooks, and the security of Agent skills and project settings.

Alongside these tools, I curate [AI-Security-zh](https://github.com/spindriftpapilio/AI-Security-zh), a Chinese-language collection of AI security learning materials, research references, frameworks, and tools. My [LLM-Jailbreak](https://github.com/spindriftpapilio/LLM-Jailbreak) repository collects jailbreak research notes and related resources.

You can also find me on WeChat through my official account, Security for AI. For project questions, feedback, or technical discussions, visit the linked repositories.
